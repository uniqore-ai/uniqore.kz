# RU / ҚАЗ локализация uniqore.kz

## Что и зачем

Главная страница и `/crm/` должны отображаться на русском или казахском языке,
не дублируя большие самодостаточные HTML-файлы. Пользователь получает язык по
локали браузера на первом визите и может явно изменить его в привычном
выпадающем меню. Английская версия остаётся на `uniqore.ai`.

## Как устроено

- Русский HTML остаётся базовым и работает без JavaScript.
- `assets/i18n.js` переводит текстовые узлы, метаданные и динамические сообщения
  демо-чата на казахский.
- Приоритет выбора: `?lang=ru|kk` → сохранённый выбор → локаль браузера
  (`kk*` означает казахский, всё остальное — русский).
- Ручной выбор Рус/Қаз сохраняется в `localStorage` под ключом
  `uniqore-language`.
- Казахский выбор добавляет `?lang=kk` в текущий URL; русский возвращает чистый
  URL. Якоря и маршрут `/crm/` сохраняются.
- Eng всегда открывает `https://uniqore.ai/` и помечен стрелкой внешней ссылки.
- `assets/language.css` оформляет один общий доступный dropdown для обеих
  страниц; на узком экране полное название языка заменяется коротким кодом.

## Пошаговая проверка

### Подготовка

1. Запустить статический сервер из корня репозитория на порту 4173.
2. Для чистой проверки удалить ключ `uniqore-language` в Local Storage.

### Сценарии

1. Открыть `/` с основной локалью браузера `ru-RU` → страница и метаданные на
   русском, в переключателе выбран «Рус».
2. Очистить ключ, выставить основную локаль `kk-KZ`, открыть `/` → весь видимый
   текст на казахском, в переключателе выбран «Қаз», `<html lang="kk">`.
3. Открыть `/?lang=kk` при русской локали → отображается казахская версия и
   выбор запоминается.
4. Выбрать «Рус» → текст меняется без перезагрузки, параметр `lang`
   исчезает, после перезагрузки остаётся русский.
5. Выбрать «Қаз» → текст меняется без перезагрузки, появляется
   `?lang=kk`, после перезагрузки остаётся казахский.
6. Повторить пункты 1–5 на `/crm/` → маршрут и локализация сохраняются.
7. На казахской версии нажать все три подсказки демо-чата → новые сообщения и
   изменившиеся подписи появляются на казахском.
8. Выбрать Eng ↗ → открывается `https://uniqore.ai/`.
9. Проверить клавиатурой Tab / Enter / Escape → меню открывается, пункты
   доступны, Escape закрывает меню.
10. Проверить ширину 375 px → в шапке виден компактный код Рус или Қаз, меню не
    выходит за экран и кнопка связи остаётся доступной.

## Ограничения

GitHub Pages не умеет выбирать язык по HTTP-заголовку `Accept-Language`, поэтому
автовыбор выполняется в браузере. Без JavaScript остаётся полностью рабочая
русская версия.
